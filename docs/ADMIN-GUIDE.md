# Admin guide

The admin portal lives at `/admin` and requires a signed-in account.

## Roles

| Role | Can do |
| --- | --- |
| **Owner** | Everything, including managing accounts |
| **Admin** | Everything except managing accounts |
| **Editor** | Create, edit and publish content; no deletions, no settings |
| **Viewer** | Read-only |

Create one account per person. Shared logins make the audit log useless.

## Daily workflow

### Handling enquiries

1. Open **Leads**. New enquiries appear first.
2. Move each lead through `new → contacted → qualified → pilot_offer → closed`, or `archived`.
3. Add an internal note on the lead after every real conversation, so anyone can pick it up.
4. Export a filtered set to CSV when you need a spreadsheet.

Statuses are a record of reality, not a to-do list — update them the same day.

### Editing page copy

1. Open **Page Content** and pick the route.
2. Edit the hero headline, subheadline, description and SEO fields.
3. Save and check the live page. Copy changes are immediate; no deployment is needed.

### Managing the hardware catalogue

**Products** holds every physical item: stickers, standups, cards, wristbands and asset labels.
Each product has variants (size, material, finish), applications, an optional spec sheet and a
gallery. Upload photography through **Media** first, then reference it from the product.

### Industries and use cases

- **Industries** are the sectors you sell into. Each gets its own landing page at
  `/industries/<slug>`.
- **Use cases** are the software modules, and each can be assigned to several industries.

Add a new sector from the portal rather than in code — it is published, audited and reversible.

### Pilot programme settings

**Settings** controls the public offer: duration, setup commitment, spots remaining, inclusions,
and the contact email, phone and address shown across the site. Keep the spots figure honest.

### Media

**Media** lists uploaded assets and their URLs. Uploads accept images and PDF up to 8 MB.
Delete unused files; the list is the only record of what the site references.

### Audit logs

**Audit Logs** is an append-only record of every administrative action, including sign-ins. Use it
to answer "who changed this and when". It cannot be edited from the portal.

## Housekeeping

- Change any password that was generated by the seed script. Do that first, before anything else.
- Review **Team** quarterly and remove accounts for people who have left.
- A forgotten password is reset by an owner from **Team**; there is no self-service reset yet.

## When something looks wrong

| Symptom | Check first |
| --- | --- |
| Public page shows stale or empty content | Whether the record is set to `published` |
| Images missing | The file still exists in **Media**; the URL has not changed |
| Cannot save | Your role — editors cannot delete, and only owners manage accounts |
| Signed out repeatedly | `ADMIN_SESSION_SECRET` may have been rotated |
