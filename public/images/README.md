Every file in this directory is a **placeholder**. They exist so the site renders without broken
images; none of them are approved product photography.

| File | Used by |
| --- | --- |
| `nfc-palawan-island-hero-tap.jpg` | Home hero, industry fallback, article fallback |
| `nfc-palawan-island-product-tags.jpg` | Product catalogue fallback |
| `nfc-palawan-island-hospitality-portal.jpg` | Use case fallback |
| `nfc-palawan-island-standup-teak.jpg` | Media library default |
| `nfc-palawan-island-nfc-stickers-macro.jpg` | Media library default |
| `nfc-palawan-island-industrial-tag.jpg` | Industrial and marine use cases |

## Replacing them

These filenames are the fallbacks referenced in code, so overwriting a file in place updates every
page that uses it. Keep the same filename and a 16:10 crop.

For anything beyond the fallbacks, upload through **Admin → Media** instead. Uploaded files land
in `public/uploads/` and are referenced by their own URLs.

Recommended: JPEG or WebP, 1600 px on the long edge, under 400 KB, stripped of location metadata.

Replace these before any public launch and delete this note when the real photography is in place.
